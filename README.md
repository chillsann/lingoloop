# Lingoloop

> 一个**没有广告、没有账号、没有服务器**的开源多语种学习应用。

只是想安安静静学门外语，不想看广告、不想被推销会员、不想把学习数据交给别人 —— 于是有了这个项目。

Lingoloop 借鉴了语言学习 App 里那套让人愿意坚持的机制（课程地图、红心、XP、连胜、每日目标、错词本），但把广告、付费墙、云账号和统计 SDK 全部拿掉了。整个应用是一堆静态文件，**打开就能用，数据只存在你自己的浏览器里**。

> 本项目为原创实现，与 Duolingo 无任何关联。Duolingo 及相关名称、角色形象、商标归其各自权利人所有。

### 关于发音（微信里也能响，整句也能读全）

9 门外语共 **432 条内置 mp3**（216 个单词 + 216 句完整例句），放在 `data/audio/`，全部由**微软神经语音**离线生成：单词用 `{词id}.mp3`，整句例句用 `{词id}-ex.mp3`。多音节短语（如 `por favor`、`안녕히 가세요`）和整句都能完整朗读，音色统一。

**为什么不用浏览器 TTS**：微信、QQ 等 App 的内置浏览器（尤其安卓 X5 内核 / iOS WKWebView）经常不提供系统语音或 `getVoices()` 返回空，只靠 Web Speech API 会「点了完全没声音」；而系统 TTS 在手机上还有「长句只读开头就停」的问题。因此主要学习链路一律播放仓库自带的 mp3。

**微信专项解锁**：微信 X5 内核要求「解锁与播放必须是同一个 `<audio>` 元素」，且 `play()` 需发生在用户手势的同步调用链里。应用只创建一个常驻 `<audio>`（带 `playsinline` / `webkit-playsinline` / `x5-playsinline`），首次触摸与 `WeixinJSBridgeReady` 双重解锁，播放失败自动重试一次。所有发音都在点击按钮的手势链内触发，离线也照常播放。

播放顺序三级降级：

1. **内置 mp3**（离线可用，Service Worker 分批预缓存，未命中时运行时按需补缓存）
2. **系统语音合成**（桌面 Chrome / Safari，仅用于自定义导入的词，按 `ja-JP / ko-KR / it-IT / pt-BR / ar-SA` 等标签选声）
3. **在线词典音频**（自定义词兜底，`<audio>` 标签跨域播放）

「设置 → 声音与发音」里能分别试听**单词**和**整句**，并显示当前环境的语音检测结果与微信解锁状态。慢速用音频 `playbackRate` 实现。内置音频由微软神经语音生成，仅用于个人学习。

**关于方言**：上海话、闽南话目前没有浏览器可用的语音合成，也没有统一的拼音方案。词条里的注音（如 `侬好 → nong ho`、`汝好 → li ho`）是**近似读音**，仅供跟读参考，实际声调和口音请以本地人发音为准。两门方言自动把「听音选词」换成「选出正确读音」题型，并跳过「例句排序」。

**关于阿拉伯语**：从右向左书写，所有显示外语文本的位置都用 `dir="auto"` 自动判定方向。日语、韩语、阿拉伯语不做例句排序题（前两者词间无空格、后者为 RTL 语序），改用拼写辨析题。

## 🚀 三种用法

**1. GitHub Pages（推荐，手机也能用）**

Pages 已经配置好：**从 `main` 分支根目录直接部署**，不需要 GitHub Actions、不需要构建步骤。推一次代码就会自动上线（仓库 `Settings → Pages` 里能看到状态）：

```
https://<你的用户名>.github.io/<仓库名>/
```

**2. 直接双击 `index.html`**

零构建、零依赖，用普通 `<script>` 加载，本地 `file://` 也能跑（PWA 安装与 Service Worker 需 HTTPS 环境，学习功能不受影响）。

**3. 本地起个服务器**

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 📝 换成自己的词库 / 加一门新语言

在「设置 → 导入自定义词库」里先选语言，再粘贴或拖入文件，会立刻变成该语言下的新单元，出现在课程地图末尾。

**JSON**

```json
[
  {
    "word": "buenos días",
    "zh": "早上好",
    "pron": "/ˈbwenos ˈdias/",
    "ex": "Buenos días, ¿qué tal?",
    "exZh": "早上好，怎么样？"
  },
  {
    "word": "vale",
    "zh": "好的；行",
    "pron": "/ˈbale/",
    "ex": "Vale, nos vemos.",
    "exZh": "好，回头见。"
  }
]
```

**CSV**（表头可选，最少两列 `word,zh`）

```csv
word,zh,pron,ex,exZh
buenos días,早上好,/ˈbwenos ˈdias/,Buenos días ¿qué tal?,早上好 怎么样？
vale,好的；行,/ˈbale/,Vale nos vemos.,好 回头见。
```

想加一门全新的语言，编辑 [`data/words.js`](data/words.js)：在 `LANGS` 里加一条配置（`tts` 用 BCP-47 语言标签；没有语音合成就设 `ttsOk: false`），再按同样结构加带 `langId` 的单元即可。几个可选开关：

| 字段 | 作用 |
| --- | --- |
| `hanzi: true` | 方言/汉字类：启用近似注音题型、跳过例句排序 |
| `skipSentence: true` | 词间无空格（日 / 韩）或 RTL 语序（阿拉伯语）：跳过例句排序，改用拼写辨析 |
| `rtl: true` | 从右向左书写：所有外语文本按 `dir="auto"` 自动排版 |

语言卡、课程地图、词库、统计、错词本都会按新配置自动生效，不用改其它文件。

新加的词若想要**离线发音**，把单词 mp3 命名为 `<词条 id>.mp3`、整句例句 mp3 命名为 `<词条 id>-ex.mp3` 放进 `data/audio/`，并把两个 id 都加进 `data/audio/manifest.js`；没放进去的词会自动走系统语音 / 在线兜底，不影响使用。可用 `edge-tts` 生成：`edge-tts --voice es-ES-ElviraNeural --text "¡Hola!" --write-media data/audio/xxx.mp3`。

## 🔒 数据在哪里

全部在浏览器 `localStorage`（键名 `lingoloop.v2`）：当前语言、XP、连胜、各语言课程进度、掌握度、错词本、自定义词库、偏好设置。

- 内置词条的发音全部来自本站 mp3，学习过程不需要联网；没有埋点、没有广告或统计脚本
- 只有「自定义导入的词」在缺少离线音频时才会请求在线词典发音
- 换浏览器 / 清缓存会丢数据 → 记得在「设置 → 数据备份」导出 JSON
- 红心按 `Date.now()` 时间戳自然恢复，不做任何服务端校验
- v1（旧的中→英版）升级时只迁移 XP、连胜和偏好，课程与词进度会重置

## 🛠️ 技术栈

原生 HTML + CSS + JavaScript，**零依赖、零构建**。

```
lingoloop/
├── index.html          页面骨架
├── styles.css          样式（暖白 + 柔绿，无 UI 框架）
├── app.js              状态、语言切换、题目生成、游戏化、路由、发音引擎
├── data/words.js       语言配置 + 11 门语言内置词库（264 词）
├── data/audio/         432 条发音 mp3（216 单词 + 216 整句）+ manifest.js 清单（约 5.8 MB）
├── manifest.json       PWA 配置
├── sw.js               离线缓存（分批预缓存发音，未命中按需补缓存）
└── icon.svg / *.png    原创图标
```

发音复用一个常驻 `<audio>` 元素优先播放仓库自带的 mp3，失败再降级到 Web Speech API（按各语言的 BCP-47 标签选声）与在线词典音频；微信 X5 内核通过首次手势 + `WeixinJSBridgeReady` 双重解锁；答题提示音用 Web Audio API 实时合成。阿拉伯语等 RTL 文字用 `dir="auto"` 自动判定方向。核心学习链路完全本地，不加载任何广告或统计脚本。
